# Hoja de vida web

Página personal de **Israel Mujia Del Castillo**, estudiante de Ingeniería en Sistemas de la Universidad Católica Boliviana “San Pablo”. El proyecto usa únicamente HTML5 y CSS3, sin JavaScript ni frameworks.

## Estructura

```text
tarea2708/
├── index.html
├── css/
│   └── styles.css
└── assets/
    └── foto-perfil.jpg
```

## Características

- HTML5 semántico con `header`, `nav`, `main`, `section`, `article` y `footer`.
- Información personal, académica, profesional, proyectos, habilidades e idiomas.
- Diseño con Flexbox y CSS Grid.
- Diseño responsive mediante `@media` query.
- Accesibilidad básica: texto alternativo para la fotografía, enlace para saltar al contenido, navegación clara y etiquetas de formulario.
- Validación HTML5 en el formulario de contacto.

## Visualización

Abrir `index.html` directamente en un navegador moderno. No se requieren dependencias ni proceso de compilación.
